系统如何工作

模型负责理解问题和选择工具，程序控制调用次数与权限，查询结果及 SQL 一并呈现。

自然语言问题→LangChain 工具调用→SQLGlot 校验→DuckDB 只读查询→可复核的回答

工程设计重点

统一指标口径

销售额只计已送达订单的商品价格；订单表和订单行表分开，避免连接后重复计数。

受限工具执行

只接受指定表的单条 SELECT，限制结果行数，并在数据库层禁用写入及外部文件访问。

知道何时拒答

没有访问、广告花费、成本和退款数据时，不编造转化率、ROI、利润或净收入。
